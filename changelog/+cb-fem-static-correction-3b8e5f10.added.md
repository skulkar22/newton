Add `static_correction_loads` to `ModalGeneratorCraigBamptonFEM`: for each given nodal load the fixed-interface static response is appended to the interior basis after the fixed-interface modes, mass-orthogonalized against them and normalized, so the reduced static solution for these loads equals the full finite-element one for any interface condition and any `fixed_mode_count`. The retained vectors are exposed as `static_correction_vectors`, `static_correction_frequencies`, and `static_correction_load_indices`, in `report`, and in `to_arrays()` and `save_npz()`.
