Fix `SolverVBD(deterministic=...)` raising a deterministic scatter buffer overflow when a reduced elastic body has contacts, provided each elastic body's contacts fit in `rigid_body_contact_buffer_size`: the solver now sizes the scatter records of the modal contact assembly from the largest elastic mode count and that list size, raises a `ValueError` at construction when this would need more than 1 GiB per launch, and raises a `ValueError` naming the list size needed when an elastic body's contacts overflow it. The sparse Schur columns of elastic links joined to each other in `rigid_articulation_solve="block_sparse_joints"` are sized from the mode count as well.
